# Simple KPI Tracking Sheet 

## Overview

A one-page Excel KPI summary created from Superstore transactional data.

## Objective

Transform raw order data into business-ready KPIs and summarize sales performance using Excel formulas and a Pivot Table.

## KPIs

- Revenue: $2,297,200.86
- Units Sold: 37,873
- Average Sales per Order Record: $229.86
- Top Sub-Category: Phones

## Tools

- Microsoft Excel / WPS Spreadsheet
- Excel Tables
- Structured References
- Pivot Tables

## Key Features

- One-page KPI summary
- Automated calculations using structured references
- Sales analysis by sub-category
- Currency and number formatting
- Pivot Table for identifying the highest-sales sub-category

## Files

- `Raw Data` – Source Superstore dataset
- `Pivot Table` – Sales by sub-category
- `KPI Summary` – Final one-page KPI dashboard

## Learning Outcome

This task strengthened practical skills in spreadsheet-based data analysis, KPI calculation, Pivot Tables, and business reporting.
